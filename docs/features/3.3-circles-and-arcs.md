# 3.3 — Circles and arcs

Requirement: **D3** (a path can follow a circle or arc, e.g. circling around another dancer).

Done when: A dancer circles another dancer.

Screens: `Stage`, `Toolbar` (load the `living-stage-design` skill). The design has no circling yet. The new tool uses the design's `path` icon. The design's `Círculo` tool is something else: it arranges a selection in a circle (C10, after the MVP).

## Decisions

- **A dancer circles another dancer, not a spot.** The centre is the other dancer's live spot during the same move, so if she walks, the circle walks with her.
- **The arc.** From her start to her spot in the figure, the circling dancer turns around the centre in the chosen direction. Her distance from the centre changes evenly from where she starts to where she ends. Clockwise is as seen on the plan, from above. Extra turns (0 to 3) add whole circles on the way. The eased progress drives the angle, so she slows in and out like everyone else.
- **Circling replaces a bend.** A path either has points (3.1, 3.2) or circles someone. Choosing a dancer to circle clears the points, and a circling path shows no handles.
- **Starting it:** with exactly one dancer selected on any figure but the first, the figure toolbar's **Circle around** tool (aria-pressed while picking) asks "Tap the dancer to circle around". Tapping a dancer saves the circle, clockwise with no extra turns. Tapping the floor, the tool again, or Escape cancels. The circling dancer stays selected. She can't circle herself.
- **Changing it:** while the selected dancer circles someone, a row above the stage reads "Around Bia" with a Direction `SegmentedControl` (Clockwise / Counterclockwise), Extra turns − 0 + (0 to 3), and **Stop circling**, which makes the path straight again.
- **She may stay put.** Circling around someone and coming back to the same spot is a full circle, so a circling path is drawn even when start and end are the same spot.
- **Circling a dancer who circles** uses that dancer's plain route (straight or bent) as the centre, so there is never a loop of dancers waiting on each other.
- **Saving** works as in 3.1: shown at once, put back if saving fails.
- **Copies and removals.** Duplicating a dance keeps every circle. Removing the centre dancer from the cast turns the path straight. New figure and Duplicate still copy no paths.

## Data model

`Path` gains `aroundId` (the cast member circled, set to null if she leaves the cast), `clockwise` (true by default) and `turns` (0 to 3, 0 by default). A path with `aroundId` has no points.

## API

- `PUT /figures/:figureId/paths/:castMemberId` takes either `{ points }` or `{ around: { castMemberId, clockwise, turns } }` (400 for circling herself or bad values, 404 for a centre dancer who isn't in the dance).
- Each path in `GET /figures` has `around: { castMemberId, clockwise, turns } | null`.
