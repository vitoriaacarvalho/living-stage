Status: proposed. Confirm the decisions marked *open* before it starts.

## Decisions (proposed)

- **Made in the browser with jsPDF and svg2pdf.js**, as §3 says. The page reuses the same SVG stage, in its print theme, so the plan looks the same as in the editor.
- **A4 landscape, one figure per page.** The header has the school, the dance title and the figure's name ("Figure 3" when it has none). The figure number is large at the top right.
- **I2's count or time:** until music ships, each page shows the figure's place ("Figure 3 of 7") and its move time. Once 4.5 is done, it shows the time in the song and the count.
- **Names under every circle**, using the dance's Labels and Color by settings; a role legend at the foot when coloring by role.
- **Notes box** as in the design, left empty to write on by hand. *Open:* keep it, or use the space for a larger stage.
- **Show and act in the header** only when the export starts from a show. *Open:* export from the editor only, or also a whole show in one PDF.
- **Started from the toolbar** with an Export PDF tool beside Present; the file downloads as `<dance title>.pdf`.
