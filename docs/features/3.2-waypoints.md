# 3.2 — Waypoints

Requirement: **D2**, its waypoints half (a path can be given waypoints). Curves, the other half, came with 3.1.

Done when: Add and move waypoints on a path.

Screens: `Stage` (load the `living-stage-design` skill). The design has no waypoints yet; they reuse the 3.1 handle.

## Decisions

- **A waypoint is one more point of the path** (3.1's `{ along, side }`), so nothing new is stored. The curve still runs smoothly through start, every point and end.
- **Up to 5 points per path** (`PATH_POINTS_MAX`). The API refuses a sixth.
- **Each point has its own handle**, the 3.1 ring, under the same rule: one selected dancer and a move of at least 1.5 m. A straight path still shows one handle halfway along, which becomes the first point when dragged.
- **Tapping the selected path's line adds a point there**, saved at once, with its handle ready to drag. The line has an invisible tap area of `touch-min` (44 px) across. It goes between the points it was tapped between, so the order of the points stays the order along the path. Once a path holds 5 points, tapping the line does nothing.
- **Letting go of a point within 30 cm of the straight line between its neighbours removes it.** Its neighbours are the points either side, or the start and end. With one point this is 3.1's rule: the path is straight again. By arrow keys the same happens within half a step (12.5 cm), so one press can still leave the line.
- **Handles are named in order**: "Bend the path of Ana" while straight, then "Point 2 of 3 on the path of Ana".
- **Saving** works as in 3.1: shown at once, put back if saving fails. Every change sends the whole list of points.

## Slices

2. ⬜ A handle on each point: drag or arrow keys move it, and letting go near its neighbours' line removes it.
3. ⬜ Tapping the selected path's line adds a point there, up to 5.
4. ⬜ Check "Done when" in the browser at iPhone, iPad and desktop sizes, then mark D2 ✅ and 3.2 ✅.

## Out of scope

- Adding a point by keyboard (arrow keys still move every point), removing a point with a button, circles and arcs (3.3).
